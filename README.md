# 📋 Health & Policy Application Form

A modern, responsive, and user-friendly web application form designed for insurance and health coverage requests. Built with pure HTML5 and modern CSS3, focusing on clean UX/UI principles, dynamic form layouts, and accessible input fields.

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Responsive Design](https://img.shields.io/badge/Responsive-Yes-success?style=for-the-badge)

---

## ✨ Features

- **📱 Fully Responsive Design:** Seamless layout adjustments across mobile, tablet, and desktop devices.
- **🎨 Modern Aesthetic:** Styled with CSS Variables (`:root`), Google Fonts (Inter), custom focus indicators, and soft drop shadows.
- **📑 Structured Sections:**
  - **Section A:** Insured's Personal & Contact Details.
  - **Section B:** Health Coverage Selection & Dependent Details Table.
  - **Section C:** Policy Terms, Premium Calculations, and Electronic Signature.
- **⚡ Semantic HTML5 Code:** Strict validation rules, clean structure, no outdated tags, and full screen-reader accessibility.
- **📊 Clean Form Controls:** Pre-styled custom input fields, radio buttons, date pickers, and dynamic data tables.

---

## 🛠️ Built With

- **HTML5:** Semantic architecture (`<form>`, `<section>`, `<input>`, `<table>`, etc.)
- **CSS3:** Flexbox, CSS Grid, Custom Variables, and CSS Transitions.
- **Typography:** [Google Fonts - Inter](https://fonts.google.com/specimen/Inter)
